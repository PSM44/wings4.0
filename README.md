# Wings4.0

**Repository role:** Portfolio Architecture and Governance Repository  
**Repository ID:** `WINGS4`  
**Canonical root:** `C:\01. GitHub\Wings4.0`

Wings4.0 coordinates the portfolio without replacing the canonical repositories, HUMAN files, products, systems, or execution environments of its members.

## Operating model

```text
Project HUMAN
→ Wings4.0 listens and consolidates
→ cross-project comparison
→ facts, interpretations, confidence, and options
→ Pablo decides
→ focalized prompts are delivered to affected projects
→ projects implement locally
→ Wings4.0 verifies resynchronization
```

Wings4.0 does not require every project to integrate. `UNRELATED` is a valid relationship.
