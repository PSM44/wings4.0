## Operating model

```text
Project HUMAN
→ Wings4.0 listens and consolidates
→ cross-project comparison
→ facts, interpretations, confidence, and options
→ Pablo decides
→ focalized prompts are delivered to affected projects
→ projects implement locally
→ Wings4.0 verifies resynchronization
```

Wings4.0 does not require every project to integrate. `UNRELATED` is a valid relationship.
