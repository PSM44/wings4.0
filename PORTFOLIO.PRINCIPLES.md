# Portfolio Principles

1. Human authority is final.
2. Projects remain independently coherent and portfolio-compatible.
3. One primary owner per major capability.
4. Local project canon governs local matters; Wings4.0 governs portfolio matters.
5. Build only after evaluating existing open-source or commercial solutions.
6. Governance must reduce ambiguity, not multiply artifacts.
7. No physical migration without path, dependency, rollback, and validation analysis.
8. Generated evidence does not replace human-readable canon.
