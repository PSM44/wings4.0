# Wings4 HUMAN Amendment Proposal — External Solution Review Principle

Status: PROPOSED_PENDING_HUMAN_APPROVAL  
Source minibattle: WINGS4_GOV_014E_DECIDE_MARKET_MONITORING_OPPORTUNITY_TRANSFER

## 1. Why this belongs in HUMAN

The preference to evaluate existing external solutions before developing or expanding custom capabilities is a permanent portfolio-governance principle.

It affects:

- project creation;
- project continuation;
- capability ownership;
- duplication;
- build-versus-adopt decisions;
- project replacement or retirement.

The detailed process does not belong in HUMAN. It is already governed by PROJECT.CONTRACT, PROJECT.INTERFACE, PROJECT.MARKET.WATCH.PROFILE and their guides.

## 2. Proposed HUMAN wording

> Before developing a new capability or materially expanding an existing one, the portfolio should consider whether an external solution, especially a suitable open-source solution, can replace, complement or integrate with the proposed work.
>
> The review may begin in any project. Each affected project evaluates local functional and technical fit. Wings4 coordinates when the candidate affects multiple projects, creates duplication, changes capability ownership, changes project purpose or lifecycle, or could replace a portfolio project.
>
> External discovery and evaluation do not authorize adoption or implementation. The final decision remains with the human owner.

## 3. Placement rule

The wording should be incorporated into the canonical Wings4 HUMAN document after:

- confirming the canonical HUMAN path;
- verifying it does not duplicate an existing principle;
- preserving the current HUMAN structure and tone;
- obtaining explicit approval of the exact amendment.

## 4. Child-project HUMAN rule

A child-project HUMAN should be amended only when an approved external solution materially changes:

- project purpose;
- primary user;
- primary outcome;
- capability ownership;
- project lifecycle or disposition.

Ordinary implementation substitutions should remain in local technical and operational artifacts.
