# Ring0 Language Standard (local)

Status: ACTIVE
Scope: `PRODUCT/RING0_SKILLSMACHINE_DIAGNOSTIC/` only
Authority: DEC-W4-055, Q-086

## Rule

All human-facing Ring0 interface text must be English only, at approximately Cambridge C1 professional standard:

- clear, natural and concise;
- executive-friendly;
- no Spanish UI labels;
- no mixed-language sentences;
- avoid awkward literal translations.

## Preserve for traceability

Canonical IDs, filenames, codes, decision identifiers and literal source path names remain unchanged when required for audit.

## Non-scope

This file does not create a portfolio-wide language standard for other Wings4 surfaces or other projects.
