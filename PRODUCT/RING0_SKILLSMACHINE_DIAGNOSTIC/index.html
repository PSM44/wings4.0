What Wings4 is: a portfolio governance product that surfaces evidence-backed findings for human decision.

What this screen does: Ring0 interactive diagnosis of SkillsMachine, plus Ring1 decision lifecycle tracking and minimal controlled intervention package export.

What to do first: open a finding, record ACCEPT / REJECT / MODIFY / POSTPONE, review the decision lifecycle, then — if ACCEPT or MODIFY — preview and export an intervention package for the target project's ORCHESTRATOR.

What it is / what it solves / how it works

Product

An operable portfolio governance tool for Pablo; management reviews live demos and declares deploy readiness.

Problem

Projects accumulate conflicts, omissions and overlap without a clear, actionable decision path.

Flow

View project → findings → evidence → decide → track lifecycle → prepare intervention package → export → update Wings4 state.

Scope boundary

Canonical-derived
