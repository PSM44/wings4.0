# Portfolio Opportunities — Skills and GRC

Purpose: Register reusable governance and skill opportunities detected by Wings4.0 without implementing them directly.

Status: ACTIVE

## OPP-W4-SG-001 — Product purpose versus implementation tool gate

Type: GRC
Status: NEW
Candidate owner: Skills/GRC governance system

Opportunity:

Formalize a reusable gate that prevents a currently installed tool from becoming the identity or mandatory architecture of a product without explicit value evidence.

## OPP-W4-SG-002 — Build, adopt, retain, replace or reject tool review

Type: SKILL_OR_GRC
Status: NEW
Candidate owner: Skills/GRC governance system

Opportunity:

Create a reusable comparative method for assessing current and future tools through functional value, privacy, maintenance, interoperability, lock-in, operational cost and fit with existing project governance.

## OPP-W4-SG-003 — Privacy-sensitive memory tool evaluation

Type: GRC
Status: NEW
Candidate owner: Skills/GRC governance system

Opportunity:

Formalize tool-evaluation controls for systems that may process Personal, Work or corporate-sensitive memory.

## OPP-W4-SG-004 — Portfolio boundary for architecture intervention

Type: GRC
Status: NEW
Candidate owner: Wings4.0 governance / Skills-GRC governance

Opportunity:

Formalize that Wings4.0 may identify architecture-related risks and opportunities but must not prescribe a project's internal architecture unless the human explicitly delegates that authority.
